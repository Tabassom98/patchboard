# Public demo boundary

The hosted demonstration is a static, read-only export of the Python app using both included synthetic scans. The export is built in a fresh temporary database and never reads the local patchboard.db or operator notes. No session token, upload form, API key, or shared writable database is published.

Queue search, state/team/signal filters, and sorting run locally in the visitor's browser. Detail pages and the ranking study are pre-rendered. The Python source remains the implementation of record for imports, lifecycle decisions, and database transactions; browser JavaScript only filters the exported sample rows. The briefing is generated by the Python rules at export time, not a live AI model.

To regenerate after changing the Python code or sample data:

```sh
python scripts/build_demo.py
```

Output is in demo/. Serve this directory with a static host. Dates, counts, and scores reflect the exported snapshot, not current vulnerability intelligence. The full application must be run locally to import scans and save investigation decisions.

The included GitHub Pages workflow runs tests, regenerates the export, and publishes only demo/. Enable GitHub Actions as the Pages source in the repository settings. This is a static demonstration; no Flask process or SQLite database runs on GitHub Pages.
